## 📖 Sobre o Projeto

O **Jogo do Número Secreto** é um projeto desenvolvido com o objetivo de praticar e consolidar conhecimentos fundamentais de desenvolvimento web.

O jogo consiste em descobrir um número secreto gerado aleatoriamente pelo sistema. A cada tentativa, o jogador recebe dicas que indicam se o número informado é maior ou menor que o número secreto, até finalmente acertar.

Este projeto representa uma etapa do meu processo de aprendizado em programação, permitindo aplicar conceitos de lógica, manipulação de elementos HTML e estilização de interfaces.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação dos elementos e componentes da página.
- **CSS3:** Estilização e organização visual da interface.
- **JavaScript:** Implementação da lógica do jogo, geração de números aleatórios e interação com o usuário.

## 🎯 Objetivos de Aprendizado

Durante o desenvolvimento, foram trabalhados conceitos como:

- Lógica de programação.
- Declaração e manipulação de variáveis.
- Estruturas condicionais.
- Funções e eventos.
- Geração de números aleatórios.
- Manipulação do DOM (Document Object Model).
- Interação entre HTML, CSS e JavaScript.

## 🎮 Funcionalidades

- Geração aleatória de um número secreto.
- Recebimento de tentativas do jogador.
- Dicas indicando se o número secreto é maior ou menor.
- Identificação automática quando o jogador acerta.
- Reinicialização da partida.
